# Library Management System

A desktop application built with C# (Windows Forms) and an Oracle database for managing a library.

## Features
- Add, update and delete books
- Add and delete members
- Manage loans and return books
- Reports and analysis: popular books,  member join rate

## Built with
- C#
- Oracle Database
- SQL (JOIN queries, CRUD operations)

## Setup
1. Run `LibraryDB.sql` in Oracle to create the database tables.
2. Open `LibrarySYS.sln` in Visual Studio.
3. Update the database connection string in  `Database.cs` with your own Oracle login.
4. Build and run the project.
